## 📂 Included Problems & Techniques

| Problem / Concept | Technique / Pattern | Description |
| :--- | :--- | :--- |
| **Remove Duplicates from Sorted Array** | Two-Pointer (Read/Write) | In-place removal of duplicates from a sorted array. |
| **Move Zeroes** | Two-Pointer (Insert Position) | Moves all `0`s to the end of the array while maintaining the relative order of non-zero elements. |
| **Rotate Array** | Array Reversal | Rotates an array to the right by `k` steps in-place. |
| **Maximum Subarray (Kadane's)** | Dynamic Programming / Greedy | Finds the contiguous subarray with the largest sum. |
| **Maximum Sum Subarray of Size K** | Sliding Window | Finds the maximum sum of any contiguous subarray of size `k`. |
| **Range Sum Query (Immutable)** | Prefix Sum | Efficiently calculates the sum of elements within a specific range using precomputed prefix sums. |
